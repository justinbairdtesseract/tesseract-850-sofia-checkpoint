# tesseract-850

### Set up Guide
start a python environment (tested as much as I could in python 3.10.9, but any over 3.8 should be fine)

in a project folder:
git clone https://github.com/xArm-Developer/xArm-Python-SDK.git
python setup.py install

make sure installed in the environment.

in main.py update IP Address to robot IP Address.

run main.py in environment.
